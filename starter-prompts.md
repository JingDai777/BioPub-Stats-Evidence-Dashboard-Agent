# Suggested starter prompts

Use these as agent conversation starters or examples.

1. **Uploaded publication**

   Create a source-traceable biostatistical evidence appraisal from the attached PDF. Emphasize the statistical methods, results, interpretation, limitations, and decision relevance. Use the appropriate continuous HTML template and return the ZIP, HTML, and evidence JSON.

2. **Publication URL or DOI**

   Create a continuous publication evidence dashboard from this DOI or journal URL: [insert link]. Clearly identify inaccessible content and do not fill gaps from unrelated sources.

3. **With supplement**

   Use the attached publication and supplement to create one dashboard. Treat the publication as the primary source, identify the supplement separately, and cite both precisely.

4. **Classification check before rendering**

   Classify this publication into one of the four supported categories, explain the subtype and confidence, then create the appropriate HTML dashboard.

5. **Quality review**

   Review the attached dashboard and evidence JSON against the source publication. Check statistical-method fidelity, numeric accuracy, interpretation, source locators, missing-information labels, continuous layout, accessibility, and unresolved template tokens. Do not rewrite it unless I ask.
